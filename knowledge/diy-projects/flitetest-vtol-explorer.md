## What's novel
A kit-bashed Flite Test Explorer that adds four lift motors for hover and a separate forward-thrust motor for cruise. The flight controller switches between the two modes through a transition control. The page is a build guide for turning a conventional speed build into a VTOL.

## How it was built
- Start from a Flite Test Explorer speed build kit and add foam board and firewall parts for the motor pods.
- Motor pods can be cut from foam board with FT Elements firewalls, or carved from solid wood as an alternative.
- Acrylic packing tape and Amazing Goop hold the parts, with wire for the rest of the work.

## Problems and fixes
none reported

## Lessons for us
- The page uses four lift motors for hover and one forward motor for cruise, so a foam kit can reach a hover mode without a separate tilting mechanism.
- The page gives no total cost. The listed part prices overstate the real cost, since foam board comes in a 50-pack and only one sheet is needed, so cost comparisons need a separate parts list.
