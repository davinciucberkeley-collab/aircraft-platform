## Summary
Conference paper (IMAV 2016, Beijing, paper IMAV2016-30) on preliminary design of electrically powered transitioning VTOL UAVs. It has a parameter table for the design case that includes a thrust-to-weight input. The text does not justify that input.

## Usable rules / numbers
- [hover_thrust_to_weight_min] Table 1, "Used set of preliminary design input parameters" (p. 221): thrust-to-weight ratio input of 1.5 (dimensionless). It is a chosen design input, not a sourced requirement, and the text does not explain it.
- [hover_thrust_to_weight_min] The only hover-related input in Table 1 is the fraction of mission time spent hovering (0.05). It is not a thrust ratio or hover margin.
- [landing_load_factor] None. The load factor G appears in wing beam deflection equations (Section 2.1) without a value.

## How we could use it
- Shows that 1.5 is used as a design input in at least one published VTOL sizing study. Weak evidence for the current value, since no reason is given.
