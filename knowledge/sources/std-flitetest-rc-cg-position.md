## Summary
Hobbyist article on RC airplane CG placement aimed at beginners. It gives a CG reference point for conventional layouts and says nothing numeric about static margin itself. Flying wings and aerobatic models are not given numbers.

## Usable rules / numbers
- [static_margin] 25 percent of MAC is given as a safe CG reference point for a first flight on a conventional wing-forward, tail-aft aircraft (section "Recommended CG Positions").
- [static_margin] A reader comment gives 33 percent of wing chord as the standard safe CG for conventional planes; this is a comment, not the article's own rule (same section).
- [static_margin] No static margin percentage is stated. No CG value is given for trainers, aerobatic aircraft, or flying wings; the article suggests a foam glider test for unusual layouts (same section).

## How we could use it
- Shows that 25 percent MAC CG is a common practice value, which sits inside a 5 to 15 percent static margin window only if the neutral point is near 30 to 40 percent MAC. Use as context, not as a threshold.
- Not usable to set static_margin limits directly.
